01Practicewho I am, what I build

I build the parts of a product that touch the real world: the camera feed, the serial port, the machine on the other end, and the screen a person uses to run it.

My work so far runs from image processing and model integration, through Python services and serial links to physical machines, to the desktop and mobile interfaces people use day to day.

I work in Python first, and reach for PyQt5, Kotlin or Flutter when the interface has to live on a desk or in a pocket.
